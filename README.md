# Caseboard — 推理工作台

把线索、证据和推断放到同一张推理板上的中文静态网页应用。

## 在线使用

GitHub 合并版：<https://haibinlai.github.io/self_thinking/>。

原 Sites 站点：<https://caseboard-haibin.gb38290171.chatgpt.site/>。两者独立部署，浏览器本地数据不会自动在两个站点间同步。

GitHub Pages 通过 `.github/workflows/pages.yml` 发布 `dist/`。推送到 `main` 的页面或发布配置改动会自动更新网站，也可在仓库 Actions 页面手动运行部署。

线上网站与本地预览使用不同的浏览器存储空间，本地已有卡片不会自动迁移到线上。

## 运行

无需安装依赖或构建。在仓库根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

然后打开 <http://localhost:8000>。也可以将 `dist/` 作为静态网站目录托管。

## 复制文字到新板子

1. 在任意应用复制一段文字。
2. 点击 Caseboard 的画布，按 macOS 的 `⌘V`（其他系统为 `Ctrl+V`）。
3. 自动新建一个板子，第一行作为板子和卡片的标题（最多 40 个字符），完整原文保存在卡片的记录中。

每次在画布上粘贴都会创建独立板子。顶部下拉菜单可以切回原板子，`＋ 板子` 可创建空白板子。在标题、笔记等输入框内粘贴不会创建板子。切换板子或新建板子前，会保存当前卡片的编辑内容。

目前支持文字粘贴，不包含图片、富文本格式或整个板子的复制导入。

## 功能

- 创建、编辑、删除线索卡片，选择线索类型。
- 四档思想尺度：世界问题、研究判断、机制 / 局部问题、观察 / 证据；通过不同尺寸和底色呈现，缩放低于 55% 时卡片显示为圆点。
- 卡片顶部按钮可快速发起连线；工具栏连线按钮可进入或退出连线模式。点击选中只更新标记，不重建卡片；指针移动达到 6 像素才开始拖动，避免轻微抖动影响点击。
- 拖动卡片、在卡片之间建立连线；卡片位置不再受固定画布边界限制。
- 点击任意连线可打开「连线详情」面板：切换连线标志（箭头、圆点、菱形、短杠、无）、调节该条连线的粗细、调换连线方向、删除连线。
- 侧栏「连线粗细」滑块统一设置新连线与未单独设置粗细的连线的默认粗细（1–10 px）；单条连线可在详情面板里覆盖该默认值。
- 拖动空白区域平移画布；画布内滚轮向上放大、向下缩小，以鼠标位置为缩放中心（35%–180%）。工具栏加减按钮仍围绕视口中心缩放。
- 顶部「案件」「详情」按钮可分别收起、展开左右侧栏；收起后画布占用释放的空间。桌面端刷新后恢复侧栏状态，窄屏默认收起并以浮层展开。
- 侧栏内也有「收起」按钮；仅收起再展开详情栏不会丢弃尚未保存的输入，选中卡片或新增卡片会自动展开详情。
- 新卡片出现在当前视口中心，画布位置与缩放比例随数据保存。
- 调整板面与连线颜色。
- 使用浏览器 `localStorage` 保存所有板子及当前板子（键名 `caseboard-workspace-v1`）。首次升级自动读取旧的 `caseboard-v1` 作为第一个板子，保留旧键作为迁移前备份；后续写入新键。数据属于当前浏览器和站点地址，不会自动同步到其他设备；清除站点数据会删除记录。

## 代码结构与导入说明

```text
dist/
  index.html   # 页面结构、内联 CSS 和交互逻辑
  board-store.js # 多板子存储及旧数据迁移
tests/
  board-store.test.cjs # 迁移、全文保存与存储失败测试
.github/workflows/
  pages.yml      # 推送到 main 时自动部署 dist/ 到 GitHub Pages
AGENTS.md      # 给后续 agent / 开发者的架构与改动指南
README.md      # 运行和代码说明
.gitignore     # 本地文件排除规则
```

初始代码来自 `Caseboard-source.zip`（站点 v2）。压缩包仅包含 `dist/index.html` 和 `.openai/hosting.json`，没有独立的 `src/`、依赖清单或构建配置。尽管目录名为 `dist`，该 HTML 包含完整应用。

2026-09-13 同步到已发布站点 v3；Sites 记录的源提交为 `c622d1a7880e6f3dcb9c6914380ecaf80cd968ed`。本次从公开站点响应提取应用 HTML，移除了托管层注入的 Cloudflare challenge 脚本；并非直接导出该源提交的归档。

`.openai/hosting.json` 绑定原托管平台的项目，未导入本仓库。页面不依赖该配置；仅使用仓库内脚本，没有第三方脚本、后端或服务器数据库。

JavaScript 以 `state` 管理卡片、连线、颜色与连线粗细；`render` 渲染卡片，`drawLinks` 绘制 SVG 连线，指针事件处理拖动，`openInspector` 管理卡片编辑面板，`openLinkInspector` 管理连线编辑面板，`save` 写入本地存储。

连线数据模型：每条连线是对象 `{from, to, marker, width}`。`from` / `to` 是卡片 id，`marker` 为 `arrow` / `dot` / `diamond` / `bar` / `none`，`width` 为该条连线的像素粗细（缺省时回退到 `state.lineWidth`）。旧版把连线存成 `['a','b']` 数组；`normalizeLinks` 会在加载和切板时自动把数组升级为对象并补默认标志 `arrow`。`drawLinks` 为每条连线渲染一条透明的 `.link-hit` 命中线（`pointer-events:stroke`）以便点击，再叠加带 `marker-end` 的可见线；SVG `<defs>` 里的箭头 / 圆点 / 菱形 / 短杠标志按当前连线颜色实时重建。

开发者速览与目录约定见 `AGENTS.md`。

## 当前限制

- 损坏的本地存储数据可能导致页面无法启动；写入失败时会显示提示。尚无自动备份导出或云同步。
- 拖动和卡片选择仍缺少完善的触屏及键盘支持。
- 连线可在「连线详情」面板里删除、改标志、改粗细、调换方向，但仍没有数据导入、导出或跨设备同步功能。

2026-09-14 合并 Sites v4（源提交 `12a9bba6da7447dbc65dfbb4ecc80c7416d59aa0`）的思想尺度和点击、连线交互，并保留 GitHub 版的滚轮缩放与侧栏折叠。应用 HTML 来自公开页面，已排除托管层注入脚本。连线端点使用卡片实际尺寸，并在远景圆点模式切换时刷新。

旧数据没有 `cardScale` 时按类型补充默认尺度；已有尺度、卡片内容、位置和连线保持不变。以上限制仍然存在。
